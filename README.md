## Simple Algorithm of an Everyday Task
Task: Brushing One's Teeth

- If haven't brushed teeth, pick up toothbrush.
- Then put toothpaste on toothbrush.
- Then use the toothbrush to scrub left and right and up and down against teeth. - Repeat actions.
- Then scrub the tongue with the toothbrush, up and down. Repeat actions.
- Rinse mouth and finally rinse toothbrush.
- Place the toothbrush back in its container for storage.
